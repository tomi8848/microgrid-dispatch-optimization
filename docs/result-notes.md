# 结果口径

- 各日库存连续衔接，即当天 24:00 的储电量等于次日 00:00 的储电量。单日确定性案例的首末储电量固定为 6000 kWh。
- 购电 Excel 沿用赛题模板的时段标签。第一问表格的 `B145` 和其余正式购电表的 `EO335` 对应结果范围外的次日首段，留空。其余正式购电表最后一行的完整合计及费用也留空。
- 论文与逐日账单采用自然日（00:00–24:00）。四小时储能区间、日初日末库存及紧急购电事件均采用各自的实际时间。
- 紧急购电是正常购电和储能执行后的正缺口，按交易时点电价的五倍结算。紧急购电表中的“无、0”表示当日无紧急购电，同日后续事件的空白日期格沿用上一日期。
- 第三问与第四问的日内更新结果中，“调整购电量”是调整后的正常购电总量。日前模型的风险储备用于限制放电，日内模型的风险余量用于优化购电，实际电池运行仍受物理边界限制。
